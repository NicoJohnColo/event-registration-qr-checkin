# Event Registration & QR Check-in

A full-stack event registration system with QR code-based check-in.

## Tech Stack

- **Backend:** Java 17 · Spring Boot 3 · Spring Security (JWT) · Maven
- **Frontend:** React 18 · Vite · Tailwind CSS
- **Database:** PostgreSQL (Supabase)

## Getting Started

1. Copy `.env.example` to `.env` and fill in your credentials.
2. See `backend/` and `frontend/` READMEs for setup instructions.

## Project Structure

```
backend/   – Spring Boot REST API
frontend/  – React SPA
```
